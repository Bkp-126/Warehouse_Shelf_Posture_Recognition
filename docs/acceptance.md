## 失败案例与下一步

1. 输入剪辑灰屏曾产生不可信候选：对照原视频顺序解码才定位问题；旧包保留，正式评分排除未复核输入。
2. 真实帧存在肩髋膝不足以判断的情况，已输出“无法判断”，不能把这些区间隐藏后宣称高准确率。
3. 本轮所有短示例预测均没有10秒提醒，真实长弯腰提醒能力未验收；合成状态机边界测试不能替代该实证。
4. 速度随运行负载明显波动，当前交付是离线分析工具，尚无稳定实时吞吐证据。

优先完成：用户补核修正版第一批的片头与人物 → 在长视频上确认货架ROI → 分批确认全部事件与可判断区间 → 固定规则后做一次冻结回归。独立视频的机位、遮挡、多人与长弯腰采集清单见 `docs/new_video_checklist.md`。未据回归输出调阈值，未训练新模型或替换默认权重。
