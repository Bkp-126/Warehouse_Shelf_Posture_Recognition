# 下一阶段：独立视频验证清单

目的：验证冻结后的事件系统对新的采集会话是否有效。当前旧视频全部按已知开发／固定回归管理，不改名当作盲测。

1. 在新日期或新的采集会话采集；尽量包含新人物，并增加不同机位和照明。登记视频来源、开始时间、帧率、分辨率、机位和场景说明。
2. 保留连续正常作业片段，记录总时长；正常片段对每小时误报尤其重要。
3. 覆盖短暂弯腰、自然出现的持续弯腰、下蹲、行走、取物、遮挡和多人交叉。不要为了测试让人员保持不舒适姿势。
4. 人工核对该机位的ROI；ROI的定义与标定步骤固定，不能借助测试结果调整动作阈值。
5. 在模型预测前冻结配置、版本、事件定义和评价规则。真值独立标注并审查，保留不确定区间。
6. 按实际采集会话／场景分组报告结果，不把相邻视频帧随机拆为训练和测试；不把独立验证素材再用于调参后继续声称独立。
7. 使用前确认素材的内部处理及对外展示范围；如不允许公开，作品集仅发布脱敏图表、获准片段和可复现脚本。

未获得这些证据前，产品描述保持“固定机位姿态风险辅助提醒原型”，不承诺跨仓库适用或上线安全效果。
