# 演示素材说明

README 中的两段新版动图来自项目实际运行的 Qt 窗口，不使用示意图或人工编造的检测结果。

| 项目 | 来源与处理 |
|---|---|
| 输入 | 仓库 v0.1.0 Release 已公开的 `video_1.mp4` |
| 视频 SHA256 | `9a50b062eacaff7aff003106c1429c20cf074e67e7aed8ddcc735ea26a5e5949` |
| 模型 | YOLO11n-pose，默认 stable 规则与已有示例货架区域 |
| 分析动图 | 实际 AIWorker 推理、跟踪和事件输出驱动界面；采样截取视频 0–12.48 秒区间，展示货架高亮、手腕提示与当前作业卡片；加速播放 |
| 回放动图 | 分析结束后，从事件列表选取真实伸手作业事件，调用程序的原始视频回放路径 |
| 采集方式 | Qt offscreen 窗口采集；不代表人工鼠标操作录屏或显示器实时性能 |
| 公开处理 | 主界面显示视频文件名，设置与日志面板收起；压缩为 GIF，未改动事件数量或提醒结果 |

货架展示轮廓绑定示例视频 SHA256，与伸手判定 ROI 分开；此次没有修改判定区域、模型或规则阈值。完整示例产生 5 次伸手事件与 5 次弯腰候选，与界面升级前一致。

本次示例没有触发持续 10 秒提醒，动图不用于证明长时间姿态提醒效果。分析与回放来自同一次会话；回放不运行模型、不增加事件。

`assets/demo.gif` 为仓库历史版本动图，单独放在 README 的旧版展示中。它的界面和画面级计数语义不代表当前版本。

新版动图沿用已公开示例，不包含未公开的长视频复核片段、人工反馈或新场地素材。
