# 人工复核与数据角色

## 本轮素材

`output/review_bundle_v1/manifest.json` 固定30个20秒片段：前20个为开发片段，后10个为同场景固定回归。开发最后片段结束875秒，回归最早开始960秒，间隔85秒。素材来自同一历史长视频，不构成独立新场景测试。

**当前复核使用v2**：v1切片存在部分灰屏和个别不足500帧的问题。v2从原视频顺序解码，保留相同的计划时间窗口，逐段核查500帧、25fps；不能把输入质量修复伪装成算法准确率改善。路径登记在 `output/delivery_locations.json`。用户在v1上的原话永久保留，不静默改绑v2哈希。

短演示视频与另一目录 video_2.mp4 内容哈希相同，因此只登记一次。长短视频的低分辨率近邻探针保存在 source_inventory.json；该近似结果不能证明独立性。短演示素材未加入这30段回归包。

时间范围先于模型初标冻结，没有按模型表现选取有利片段。未经用户确认，不变更标签到 verified，也不公布正式识别指标。若必须改规则，先仅用开发片段；固定回归结果不得用于逐轮调阈值。

## 每批最多5段

打开 batch_01.html 到 batch_06.html。先看未叠加预测的原始视频，再对照 candidates/clip_XX.json。模型初标与 labels/clip_XX.json 分开保存。空 events 表示尚未标注，绝不是“没有事件”。

长视频的 ROI 还未人工确认，因此初标只含姿态候选，伸手覆盖仍待补充。需要在主界面打开该来源视频，画货架区域并确认；后续同源同机位片段才能使用这份 ROI。不能把1920×1080示例的区域直接套到2560×1440长视频。

用户每段确认：

1. 画面里有哪些人物，给出片段内稳定编号 A/B/C；跨片段无需声称是同一个真实人。
2. 真正能看清的弯腰区间，精确到约0.1秒；区分下蹲、坐姿和转身，难以区分则标成无法判断，写入 notes。
3. 手腕进入已确认货架区域的区间；没有 ROI 的片段暂不评价 reach。
4. 事件中真正可判断为弯腰的时间区间 valid_intervals。遮挡时间不能充入10秒演示提醒时长。
5. 检查模型轨迹与人工人物编号的对应；换模型或换会话后重新确认对应，不能仅复制 track_id。

可以直接用自然语言给出“clip_01：A 在1.2～4.8秒弯腰，5.0～6.0秒遮挡”等结果，再由助手录入，但助手不能自行替用户填写审核完成。

## 标签格式

```json
{
  "schema_version": 1,
  "review_status": "verified",
  "reviewer": "真实核验人",
  "reviewed_at": "实际确认时间",
  "annotation_complete": true,
  "evaluated_event_types": ["bend"],
  "data_role": "development",
  "video_sha256": "待评测视频的SHA256",
  "evaluation_range": [0, 20],
  "mapping_session_id": "已核对的预测会话编号",
  "track_person_map": {"1": "A"},
  "events": [{
    "person_id": "A", "event_type": "bend", "roi": "",
    "start_time": 1.2, "end_time": 14.0,
    "valid_intervals": [[1.2, 6.0], [6.2, 14.0]]
  }],
  "normal_intervals": [[15, 20]]
}
```

以上纯粹是格式示例，不能复制为本项目真值。只有完成整段核验才设置 annotation_complete=true。reach 的 roi 为确认区域名；bend 的 roi 为空字符串。记录时间以片段自身0秒起算，原视频偏移另外保存在manifest。

没有配置ROI时必须明确 `evaluated_event_types=["bend"]`。伸手人工反馈可以独立留存，但不进入该范围的分子、分母和无法判断覆盖率。确认区域后另行评价reach。第一批用户按整秒提供时间，记录 `annotation_time_resolution_seconds=1`，不能包装成0.1秒精标。

## 评测规则

同人物、同类型、同ROI的事件进行时间IoU≥0.5的一对一最大匹配；额外重复预测记为FP并另计重复事件。被评测区间截断的事件会被拒绝，防止持续时长和提醒被错误裁剪。所有区间内预测都必须有人物对应，不能忽略没有对应的困难预测。

辅助提醒真值从人工姿态 valid_intervals 累计达到配置时长时派生，只是演示策略应否触发的标签。它不是人体健康／安全风险标签。正常视频误报率同时报告实际观察时长；短视频换算出的每小时数只作描述。

无法判断覆盖率基于当前已检测／短期保留轨迹的姿态和ROI通道时间，不代表对完全漏检人物的总体召回。模型首次没检测到的人需要人工事件标签才能反映为漏报。

## 当前不能填补的缺口

独立场景视频、长视频ROI、动作类别覆盖和正式人工标签均需后续确认。自动初标数量、截图数量或测试通过数，都不能替代这些确认。
